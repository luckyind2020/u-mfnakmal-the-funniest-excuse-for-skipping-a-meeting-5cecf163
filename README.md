One razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting. An AI judge pairs excuses head to head and crowns the biggest laugh.

The entry: "Can't make it — I'm in a workshop on how to decline workshops."

## Run it

```sh
python3 main.py
```

`main.py` reads the excuse from `entry.txt`, validates it (one line, 1–200 characters, not only whitespace), writes it to `/output/entry.txt`, and prints it.
